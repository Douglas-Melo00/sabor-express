        <h1>🍔 Sabor Express</h1>
        <p>O <strong>Sabor Express</strong> é uma aplicação de linha de comando (CLI) interativa desenvolvida em Python para o gerenciamento ágil e prático de restaurantes.</p>

        <h2>✨ Funcionalidades</h2>
        <ul>
            <li><strong>Cadastrar Restaurante:</strong> Permite adicionar novos estabelecimentos ao sistema.</li>
            <li><strong>Listar Restaurantes:</strong> Exibe todos os restaurantes cadastrados na base de dados.</li>
            <li><strong>Alternar Estado:</strong> Ativa ou desativa o status de funcionamento de um restaurante específico.</li>
            <li><strong>Interface Limpa:</strong> Tratamento de erros e limpeza de tela automática para melhor experiência do usuário.</li>
        </ul>

        <h2>🚀 Tecnologias Utilizadas</h2>
        <ul>
            <li><span class="badge">Python 3.x</span> Linguagem principal da aplicação.</li>
            <li><span class="badge">OS Module</span> Utilizado para limpeza do terminal e gerenciamento do ciclo de vida da aplicação.</li>
        </ul>

        <h2>⚙️ Como Executar o Projeto</h2>
        <p>Para rodar esta aplicação localmente na sua máquina, siga os passos abaixo:</p>
        
        <ol>
            <li>Clone este repositório para o seu computador:
                <pre><code>git clone https://github.com/Douglas-Melo00/sabor-express.git</code></pre>
            </li>
            <li>Acesse o diretório do projeto criado:
                <pre><code>cd sabor-express</code></pre>
            </li>
            <li>Execute o arquivo principal utilizando o Python:
                <pre><code>python app.py</code></pre>
            </li>
        </ol>
